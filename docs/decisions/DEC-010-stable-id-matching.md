# DEC-010：稳定 ID 匹配算法

> 状态：Accepted（2026-09-15，M4 内冻结）
> 日期：2026-09-15
> 负责人：linductor
> 冻结里程碑：M4
> 替代/被替代：无

## 背景与问题

总计划将 `DEC-010`（稳定 ID 匹配算法）列为 M4 最迟冻结的决策，暂定默认值为「门控后
贪心匹配起步」。设计 §16 要求：匹配成本可综合 IoU、中心位移、文字相似度、类别和
来源；使用门控后的贪心或二分图匹配；区域内容或位置在合理范围内变化时沿用 ID，发生
分裂、合并或大幅变化时分配新 ID 并增加快照 generation。M4 立项必须冻结：

1. 匹配算法形态（贪心 vs 二分图）与门控定义；
2. 成本函数组成与权重语义；
3. 分裂/合并事件的判定与 generation 递增规则；
4. 多源融合时证据关联门控（IoU/包含/中心距离）的阶段范围。

## 决策

### 1. 门控后贪心一对一匹配起步

`StableIdTracker` 在上一快照区域与当前融合区域之间做匹配：

- **门控（gate）**：候选配对必须至少满足其一——IoU ≥ `match_iou_threshold`，或中心
  位移 ≤ `center_gate_ratio × 上一区域对角线长度`。门控未通过的配对不进入匹配，保证
  「相邻但语义不同」的目标不会仅因距离被关联。
- **成本（cost，越小越好）**：`cost = Σ w_k · (1 - s_k)`，信号 `s_k ∈ [0,1]` 为 IoU、
  中心位移相似度（`1 - 位移/门控半径`）、文本相似度（规范化后 Levenshtein），权重
  显式可配置且和为正即可（不强制归一）；类别/来源不兼容在门控阶段直接排除，不入成本。
- **贪心**：所有通过门控的配对按成本升序、再按（上一索引、当前索引）升序排序，依次
  占用；一侧已被占用则跳过。全程确定性，无随机性、无浮点不确定排序。
- 一对一贪心是刻意取舍：分裂/合并只做**事件识别**（见第 3 节），不做多对多最优
  匹配；ID 保持率在极端布局变化下有限，但实现小、可解释、可测试。

### 2. 文本相似度参与成本

文本相似度对双方均有非空文本的配对生效：两侧文本经 `normalize_text` 规范化后按
Levenshtein 距离计算 `1 - dist/max_len`；任一侧为空则该信号权重为 0（不惩罚）。类别
兼容性在门控阶段处理：两侧均为检测来源且类别不同（双方 label/class_id 均非空且不等）
的配对直接排除。

### 3. 事件与 generation 规则（`RULE-09`）

- 事件：`kRetained`（沿用 ID）、`kNew`（分配新 ID）、`kSplitSource`（上一区域未匹配
  且 ≥ 2 个新 ID 区域落入其bounds）、`kMergedSource`（当前区域携带 ≥ 2 个未匹配上一
  区域落入其 bounds）。
- generation 递增（快照级）：发生任一分裂或合并事件，或保留比例（retained /
  上一快照区域数）< `generation_retention_ratio`（默认 0.5，上一快照非空时）。单纯
  新增/消失少量区域不递增，避免局部 UI 变化让全部陈旧化。
- 稳定 ID 只在跟踪会话内稳定（`RULE-09`）：tracker 随会话创建，`reset()` 显式重置；
  不承诺跨会话、跨应用重启或跨设备唯一。

### 4. 证据关联门控的阶段范围

融合关联（`FusionOptions`）以 **IoU 门控 + 包含关系门控 + 兼容性谓词**为阶段一范围；
设计 §16 列举的中心距离信号在本阶段只作为 trace 观测量输出（记录每对的 IoU、包含
比例、中心位移），不作为独立合并门控——避免「相邻但语义不同的图标和文本仅因距离
较近合并」。补充距离门控属于阈值配置演进，不破坏契约。

## 备选方案

- 二分图最优匹配（匈牙利/Hungarian）：ID 保持率理论上更优，但实现与测试面显著更大，
  且缺乏标注数据证明收益，列为 `RISK-2026-11` 的触发后演进项，被否为起步方案。
- 纯 IoU 阈值匹配：无法区分同位不同物（遮挡切换），文本信号缺失，被否。
- 每帧全部分配新 ID：语义上等价放弃跟踪，违反设计 §16，被否。
- generation 每帧递增或由调用方自管：失去陈旧性校验的库内保证（§26 验收），被否。

## 影响与风险

- `StableIdTracker` 落在 `mirador::fusion`（`DEC-013`），状态随 `PerceptionSession`
  持有；快照发布不可变，tracker 状态仅会话内可见。
- 贪心一对一在密集重叠 UI 上可能产生次优指派；`RISK-2026-11` 记录触发条件（M5 基准
  ID 保持率不达标），届时以决策记录扩展，不静默更改语义。
- generation 规则是库内确定性规则，不依赖墙钟；上层可以拒绝携带过期 generation 的
  动作（§16）。

## 验证方式

`M4-04`/`M4-08`：稳定 ID 单元测试覆盖保留/新增/分裂/合并/generation 递增边界与
确定性平局；属性测试保证任意合法输入下无越界与崩溃；全预设矩阵通过。见
`tests/fusion/`。
