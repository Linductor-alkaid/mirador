## 目标、范围与非目标

承接 [Issue #41 的连续感知诉求](https://github.com/Linductor-alkaid/mirador/issues/41#issuecomment-6258623068)
及 [2026-10-20 日期化后续](https://github.com/Linductor-alkaid/mirador/issues/41#issuecomment-6285521869)：
复用稳定区域，把注意策略用于 OCR/Detector 之前，维护可查询实体与关系，在可信语义
变化时按调用方策略发布增量。图像变化、语义变化和通知三者分别记录。维护方向为
「增量视觉状态 + 事件驱动理解 + 按需 VLM」的分层资源模型：Mirador 的高频低成本
观测维持内部状态，事件驱动的语义理解是下游可选升级，其开关不影响状态层连续性；
关系/事件差分须携带来源、实例代际、证据时间窗与开始/更新/结束语义，遮挡/未分析/
跟踪丢失不等同于确认消失，输入源重置必须显式终结旧代事件（DEC-026 第 8 节）。

不负责屏幕采集、LLM 推理、任务重要性推断、线程/定时器/任务队列、动作执行；
不承诺只凭未识别文本定位目标，也不承诺未观察区域立即有最新语义；不引入视觉
token 压缩模型/权重/runtime 或模型序列协议（MiniCPM-o 仅为下游研究参考，
见 DEC-026 第 8 节）。M8 先独立修复直接性能问题，M9 分阶段进入评审和实施。

## 验收数据与方法

在 [既有评测集约定](../benchmarks/evaluation-scenes.md) 下冻结新后缀场景 ID，
不得修改 M7 场景后沿用其历史数字。最少包含：静态密集页、光标/时钟/局部动画、
滚动、弹窗开关、主题/窗口布局切换、单字小变化、相似图标、OCR+YOLO 重复目标、
按钮文字/图标/容器嵌套、焦点切换、source 重建、迟到结果与处理积压；
以及 2026-10-20 后续补充的六条序列——相似对象交换、遮挡后重捕获、关系改变
（遮挡/层级/布局）事件化、乱序/迟到结果不覆盖新状态、输入源重置后旧代事件
显式终结、关闭事件驱动语义升级时状态层保持连续。

伪 Backend 用带 GT 的确定序列验证机制；真实模型用受控截图及人工实体/关系/事件
标注验证质量。校准集与留出集按页面/任务拆分，M9-06 调参不得查看留出标签后再
修改门槛。至少每类 10 段真实序列、每段 ≥100 帧，报告实际正/负事件分母；数据
不足保持对应真实质量门槛未完成。图片、权重与原始文字不进入仓库或默认日志。

对照 A 为每个被处理帧全屏 OCR+Detector；B 为现有变化/缓存/跟踪组合；C 为新增
注意+增量协调；D 为 C 加语义稳定化/通知。四组使用相同输入、Backend、线程、模型、
候选上限、公共时间预算和采样策略；不能用较少输入帧或降低分辨率伪造加速。
允许另列不限时全量质量 oracle，不能混入有限预算性能对照。

## 验收标准

以下为拟定门槛；机制测试要求精确通过，真实质量与性能仅对冻结数据/平台有效。
0 分母写“不适用”并补有该事件的序列，不以 0/0 当作成功。

| 编号 | 可执行标准 | 证据 |
| --- | --- | --- |
| AC9-01 | 固定重复/包含/普通重叠/冲突夹具全部输出预期实体与关系，禁止传递误合并；输入证据可追溯率 100%，跨 epoch/关系环/非法几何整批拒绝 | 伪 Backend 与融合回归；旧融合默认结果不变 |
| AC9-02 | 真实留出集：重复实体合并 precision ≥99%、recall ≥95%，父子关系 precision ≥98%、recall ≥90%；相似图标/相邻异义文本误合并率 ≤1%，按场景列混淆计数 | 人工 GT；匹配先按 IoU≥0.5 一一对应，关系须端点和类型都正确；精度分母为输出关系/合并，召回分母为 GT |
| AC9-03 | 初次填充后 300 帧完全静止序列 OCR/Detector forward 均为 0、事件为 0；局部变化验证焦点外复用；修改模型/参数/ROI/预处理版本必须失效；精确单字变化不得被相同 dHash 隐藏 | 伪序列 + 真模型；状态标明复用验证帧与覆盖，不能只查缓存命中 |
| AC9-04 | 焦点面积 ≤20%、无布局切换的冻结局部变化场景，C 相对 B 的 rec 行数和 Detector 输入总像素分别减少 ≥70%（有正分母场景），有效焦点实体召回下降 ≤1 个百分点；完整提交→可查询状态 p95 降低 ≥50% | 实际 forward/像素计数 + 同机计时；相同置信门槛，不能只减少事件数 |
| AC9-05 | 未变区域 ID 延续率 ≥99%；滚动补偿后的焦点实体延续率 ≥95%；布局/窗口/source epoch 变化时旧引用当次失效，旧绑定结果采纳次数 0 | GT 身份匹配；补偿失败显式 unresolved，不以跳到相似对象维持 ID |
| AC9-06 | 两次完成顺序倒置、重复 accept、跳帧、策略/模型切换、旧 source、ROI 内容已变均可复现；stale/错误提交不改变已确认快照、generation 或完整缓存 | 100 组确定性置换 + 故障注入，逐项拒绝原因可查 |
| AC9-07 | 调用方 harness 以 60 fps 输入、5 fps 处理模拟 10 分钟；始终 ≤1 在途+1 待处理帧，替换/拒绝计数准确；库新增状态 ≤配置字节上限，队列长度不随时长增长 | 虚拟帧序列模拟 + 一次真实耗时集成；图像生命周期由调用方保持，无后台库线程 |
| AC9-08 | 单次 OCR 噪声不产生已确认文字事件；连续 2 次有效独立观测后最多 1 个事件；消失只有被覆盖区域缺失时确认，遮挡/未分析/跟踪丢失输出为可查询中间观测态而非确认消失；事件携带来源、实例代际、证据时间窗与 begin/update/end 语义，同实体持续存在不重复发事件；通知抑制后内部状态仍更新；切换焦点可立即查询已知状态且显式 freshness | 伪序列精确断言；真实事件 precision ≥99%、recall ≥95%，每 1,000 个无 GT 变化的被处理帧误通知 ≤1 |
| AC9-09 | 焦点外弹窗/布局变更在下一被处理帧产生结构失效记录；若策略允许通知则同步可 drain，不能等全量 OCR；队列容量/字节溢出可观测且置 resync_required；query 可恢复当前确认状态 | 外围负向矩阵、事件溢出与策略切换测试；unknown 不冒充未变 |
| AC9-10 | kNone 路径新增协调开销相对 B 的 p95 ≤max(B p95×5%, 0.1 ms)；0/90/180/270、stride、奇数尺寸与坐标恢复通过；ASAN/UBSAN、架构/默认构建、取消/预算与适用跨平台 CI 通过 | 固定参考机至少 20 次重复；计时分开核算 M1 与协调层，TSAN/故障注入覆盖共享缓存 |
| AC9-11 | 2026-10-20 补充序列逐条精确通过：相似对象交换时稳定 ID 无证据不迁移；遮挡后重捕获延续原 ID（或按 DEC-010 规则显式换新并记录原因）；遮挡/层级/布局关系变化事件化为 update；乱序/迟到结果不覆盖新状态；输入源重置后旧代未闭合事件以 source reset 显式终结（不以 disappearance 收尾）；关闭事件驱动语义升级时状态层与事件序列保持连续 | 伪 Backend 确定性序列 + 故障注入；逐序列断言，不允许以“相似即同 ID”“丢失即消失”或“重置即静默”通过 |

事件延迟同时列“被处理帧数”和墙钟时间：默认确认窗口为 2 次有效观测，因此
真实稳定变化在第 2 次有效观测后必须立即可 drain；上游多久送来两帧不属于库保证。
布局失效采用当次处理立即失效规则。通知准确率只比较调用方策略要求发布的 GT
事件；同时单列全部视觉变化的覆盖/漏检，不能过滤难例提高 precision。
